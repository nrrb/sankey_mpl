# Changelog

Notable changes to this project, newest first.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
version numbers follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Because the layout deliberately reproduces the geometry of an upstream library, treat
**any change to resolved geometry as breaking**, even where the API is untouched: a
diagram that moves is a broken diagram for anyone diffing rendered output.

## [0.1.1] - 2026-08-13

### Fixed

- `Node.column` and `Node.y` are typed `int` and `float` rather than `int | None` and
  `float | None`. Both attributes are public and documented, but the optional
  annotations described an internal construction state that no caller can observe, so
  any consumer running a type checker had to add a redundant `assert` or
  `# type: ignore` to do arithmetic on a documented attribute. Runtime behaviour is
  unchanged, verified by byte-identical rendered output across all five test datasets.
- The `Typing :: Typed` claim is now checked rather than asserted. The package shipped
  `py.typed` while nothing had ever run a type checker over it; mypy runs in CI and the
  twelve errors it reported are fixed.

### Note on version identity

0.1.0 and the repository briefly shared a version number while their sources differed,
because the typing fix above landed after 0.1.0 was published. Nothing installed from
PyPI was affected, and the difference was confined to type annotations, but the version
string could not be used to identify the code. This release exists so the published
artefact and a checkout agree again. Found by a downstream consumer, which is the point
at which it stops being theoretical.

## [0.1.0] - 2026-08-12

First tagged release, so everything here is new. There is no earlier version for
anything to have changed from.

### Added

- `render_sankey(nodes, links, config=None)` returning a `SankeyFigure`: the figure
  owning entry point.
- `draw_sankey(ax, nodes, links, config=None)` returning a `SankeyDrawing`: draws into
  an axes the caller owns, for embedding in a larger figure. Both entry points resolve
  identical geometry through the same seam.
- `build_frame(nodes, links, config=None)` returning a `Frame`, so an embedder can
  learn the diagram's final pixel size before committing to a place to put it. The
  gutter and `preserve_column_pitch` both move the final width, so it cannot be
  computed from `width_px` alone.
- `compute_layout(...)` returning a `SankeyLayout`: the layout alone, with no
  matplotlib involved, for inspection, testing, or driving another backend.
- `save(figure, path, config=None)`: SVG, PDF and PNG with byte reproducible output,
  achieved by fixing the SVG id salt and dropping embedded timestamps. Reproducible
  within one matplotlib version, not across versions.
- `text_width(text, config=None)`: string width in pixels in the configured label
  font, for sizing the label gutter from real data instead of guessing.
- `DEFAULT_CONFIG`: every tunable as a plain dict entry. Unknown keys raise rather
  than being ignored, so a typo is an error and not a silently unchanged picture.
- A pixel contract: one data unit is one point is one pixel, so `label_font_size_px`
  and every width key take pixel values directly and the figure lands at the size it
  was configured for.
- Genuinely vector output. Ribbon gradients are cut into flat filled slices, each an
  exact piece of the same cubic curve by de Casteljau subdivision, so nothing
  rasterises and SVG and PDF stay scalable with selectable text.
- Refusal to draw misleading diagrams. Cycles, backward links, disconnected graphs,
  nodes shorter than their own links, a gutter too narrow for its labels and padding
  wider than the figure all raise.
- Label handling for static output: a drop rule for nodes too thin to label and a
  per column separation pass for whatever still collides.
- `py.typed`, so type hints are visible to type checkers in consuming projects.
- Geometry verified against golden data generated by running the upstream JavaScript
  library, across five datasets of deliberately different shapes.

### Known limitations

- The layout resolves once and does **not** recompute when a figure is resized. An
  embedder that resizes the host figure after drawing gets a stretched diagram.
- With the default label side mode, the column left of the plot middle points its
  labels right and the column right of it points them left, into the same gap. The
  separation pass is per column and cannot see that pair, so those two labels can
  overlap when the column pitch is narrower than both labels combined. See the Labels
  section of `docs/usage.md` for how to check your own data.
- Ribbons do not taper. A node whose inflow and outflow differ is sized by the larger
  and its ribbons keep their source thickness, matching upstream.
- Horizontal orientation only.

### Note for anyone who installed from `main` before this tag

`main` was installable by git URL before this release existed, and `__version__` read
`0.1.0` throughout, so a pre tag install cannot be told apart from this release by
version alone. If you installed before 2026-08-12 the visible difference is label
placement: `label_side_mode` defaulted to `"left"` with a 200px `label_gutter_px`, and
now defaults to `"outside"` with a 3px gutter. Reinstall at `v0.1.0` to be sure of what
you have, and pin to the tag rather than the branch from here on.
